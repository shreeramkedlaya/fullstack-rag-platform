# 📦 FullStack Core

Welcome to the FullStack application. This repository utilizes a multi-layered Microservice architecture featuring a React SPA, a Django Core API, and a FastAPI AI Microservice.

## 🚀 Quick Start

### 1. Start the Django API Gateway
```bash
cd backend
python manage.py runserver 8000
```

### 2. Start the AI Microservice
```bash
cd ai_microservice
fastapi dev main.py --port 8001
```

### 3. Start the Frontend SPA
```bash
cd frontend
npm run dev
```
